# Środowisko — The Genesis Order

- Użytkownik potwierdził Windows.
- Sklep, wersja gry, build, DLC i dokładna ścieżka instalacji: **nieznane**.
- Pakiet inwentaryzacyjny celuje w Windows PowerShell 5.1 i nie wymaga dodatkowych narzędzi. Wykonanie po stronie użytkownika jeszcze niepotwierdzone.
- Agent sandbox nie ma PowerShell ani instalacji gry. Nie ma testu Windows ani testu in-game.
- Wymagania ekstrakcji, edycji, budowania i testów zostaną zapisane dopiero po rozpoznaniu raportu.
