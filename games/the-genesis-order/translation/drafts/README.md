# Robocze tłumaczenia TGO

Śledzone częściowe zwrotki po stabilnych ID. `ui-01/` zawiera 130 rekordów (127 niepustych pól; 3 chronione pozostają puste); `hints/` zawiera dwie rozłączne partie 65 i 35 wskazówek. Łącznie 227 niepustych pól, w tym celowo zachowane nazwy i skróty. Teksty wymagają redakcji i testów w grze; to nie jest patch.

Źródłowy eksport `../export-v1/` i źródłowy ZIP v1 pozostają niezmienione. Scalaj zwrotki po ID za pomocą `tools/merge_translation_batches.py`, bez nadpisywania poprzedniej pracy. Nie zmieniaj źródła, kontekstu ani tokenów. Kolejne części tłumaczeń zapisuj tutaj i śledź w Git, nie wyłącznie na Drive.
